# Simple ETL Project

This is a minimal **ETL (Extract, Transform, Load)** pipeline built in Python.  
It demonstrates how to extract data from a CSV file, transform it, and load the cleaned data into another CSV file.

ETL Steps

Extract
Reads data from input.csv.

Transform
Removes rows with missing values.
Adds a new column name_upper with uppercase names.

Load
Saves the transformed data into output.csv.
